# Agentic Robotics / Embodied Harness 周报（2026-10-19）

> 检索窗口：2026-10-12—2026-10-18（Asia/Hong_Kong）；必要时回看近 30 天补漏。  
> 证据口径：除特别注明外，性能数字均为作者论文、作者项目页或官方仓库报告；截至 2026-10-19，未检索到本期新论文的独立复现。不同任务、机器人、策略骨干、执行预算和成功判据不可直接横向排名。

## 本周结论

- **运行时正在学习“何时介入”，而不只学习“介入后做什么”。** VeriVLA、PAV、ForkCast、ACRO 与 *When to Ask for Help* 分别从动作方差、策略内部表示、世界模型预测、成功价值和信息价值出发，决定验证、重观测、重规划、回退或继续执行。
- **自我改进开始先做失败归因，再决定改 harness 还是改权重。** AdaRSI 先由 coding agent 改技能与 harness，再从保存状态重试失败子步骤；只有仍不可靠的子步骤才进入自采数据微调。这比“所有失败都训练”更接近可治理的 embodied RSI。
- **长期记忆正在分化成三类控制信号。** VaM 把近期价值预测当任务进度记忆，LTM/Mem4Act 把视觉历史压成固定预算 latent memory，PAM 把用户日常流程写成可反思更新的 FSM。三者分别偏向进度、视觉证据和程序性习惯。
- **评测开始控制“多试几次就成功”的假学习。** SEAR 明确区分 retained experience 与 reroll、熟悉任务、特权状态和预算效应；WorldOracle 用同初始观测与同动作序列的真实执行作为世界模型参照。二者比单看成功率更适合判断 harness 是否真的学到了可迁移机制。
- **开源状态参差。** ACRO、LTM 与 WorldOracle 已有实质代码；PAM 有作者项目页链接的仓库，但当前首页缺少论文说明；ACCRUE 明示代码 coming soon，ForkCast 明示后续发布，其余多为论文先行。

## 优先阅读顺序

1. **SEAR**：先统一“什么算学习”，否则所有自我改进结果都可能被 reroll、预算或熟悉任务混淆。
2. **AdaRSI**：本周最直接的 harness/策略责任归因方案；适合与 RoboRSI、Zetta、SHAPER 做同协议比较。
3. **VeriVLA + PAV + When to Ask for Help**：共同回答验证/慢模块何时值得调用，并暴露检测器数据泄漏与查询成本问题。
4. **ACRO + ForkCast**：把失败恢复从二元触发扩展为“继续、重观测、重规划、物理回退”的候选决策。
5. **VaM**：将 value 同时用于历史压缩与在线 RL，是记忆和学习闭环的清晰结合。
6. **LTM + PAM**：分别代表固定预算 latent memory 与可编辑程序记忆；两者均有真实机器人证据和公开入口。
7. **ChunkAct**：把经验编译成 autonomous chunks，显著减少在线 LLM 调用；需重点审查 chunk 边界与失败回传。
8. **WorldOracle**：适合建立“世界模型分数是否预测恢复收益”的独立验证协议。

## 新论文与版本更新

### 1. 评测方法与研究版图

#### SEAR: Benchmarking Self-Evolving Agentic Robots

- **日期/版本**：2026-10-13，v1
- **链接**：[论文](https://arxiv.org/abs/2610.18792)
- **机制**：把 code-as-policy、agent-as-policy 与自动研究置于同一评测框架，显式控制 retained experience、reroll、熟悉任务、特权状态、预算与随机性，判断跨 episode 提升是否来自可保留、可迁移的经验。
- **作者证据**：覆盖 7 个 frontier LM、330 个仿真任务、5 个物理任务和累计超过 4 年的 agent runtime。作者发现简单任务中 reroll 可追平长时会话；共享 routine 可迁移，而任务特定解法往往不能迁移。
- **限制**：摘要称发布 benchmark/code，但 arXiv 页面未给出可核验代码链接；仍需审查各模式的预算等价性。无独立复现。

#### Towards Agentic Robots: A Systematic Survey and Taxonomy

- **日期/版本**：2026-10-14，v1
- **链接**：[论文](https://arxiv.org/abs/2610.20442)
- **机制**：用 Model / Data / Environment / Harness 四层与 17 个类别整理 agentic robotics。
- **证据与限制**：是综述与分类法，不是机器人性能实证；适合仓库导航与术语统一，不应作为方法有效性的证据。

### 2. Harness / 技能演化与失败归因

#### AdaRSI: On-Demand Recursive Self-Improvement for Embodied Agents

- **日期/版本**：2026-10-14，v1
- **链接**：[论文](https://arxiv.org/abs/2610.20474)
- **机制**：coding agent 先改技能与 harness；对持续失败的子步骤从保存状态重试以归因；仅微调仍不可靠的子步骤，数据由系统自主采集并复用此前任务经验。
- **作者证据**：GR00T N1.5、RoboCasa365 全 50 个目标任务、无人工示范；未见组合任务成功率 4.6%→13.8%。相较“每个子步骤都微调”，作者称成功率略高，同时只用 28% GPU 时间和 22% 自采示范。
- **限制**：仿真证据，未见真机与官方代码；保存状态重启带来现实中难以复现的干净反事实。无独立复现。

#### EmbodiedEvo: Transferable Skills and Lessons from Physical Feedback

- **日期/版本**：2026-10-13 v1；2026-10-14 更新为 v2
- **链接**：[论文](https://arxiv.org/abs/2610.18867)
- **机制**：把执行反馈蒸馏为可复用代码 Skills 与诊断 Lessons；在一个 Playground 场景/任务上获得经验，冻结后交给独立 agent 迁移到未见场景，不更新权重。
- **作者证据**：RoboDojo-Sim 平均 score 44.48、success 37.82%；Astra 获得的经验使 Sol/Luna 分别提高 8.86/5.50 个百分点；相对原始历史保持相近效果并降低 53% 执行成本。
- **限制**：作者结果；接触丰富任务仍困难；“officially verified results”不是第三方复现。未见官方代码。

#### ChunkAct: Compiling Experience into Autonomous Robot Action Chunks

- **日期/版本**：2026-10-13，v1
- **链接**：[论文](https://arxiv.org/abs/2610.18874)
- **机制**：离线把经验编译为自主 primitive chunks；在线一次 LLM 调用启动 chunk，成功时不再回到语言模型，仅在失败时返回 planner。测试时 chunk 内无外部记忆。
- **作者证据**：LIBERO-Pro 上相对作者所选 agentic SOTA +5.0 个百分点；LLM 调用减少 2.9×、输入 token 减少 4.4×、输出 token 减少 2.3×。
- **限制**：协议内作者比较；需检验新型扰动、chunk 边界错误与低层失败是否能可靠上浮。未见代码。

### 3. 自适应验证、执行时控制与失败恢复

#### VeriVLA: Adaptive Test-Time Verification for Flow-Based VLAs

- **日期/版本**：2026-10-15，v1
- **链接**：[论文](https://arxiv.org/abs/2610.21985)
- **机制**：用两个初始 flow-policy 样本测量 chunk 内时间变化和样本间方差；仅在临界状态触发 JEPA latent world model，对候选 action chunks 的未来任务进度排序。
- **作者证据**：3 个真机任务平均 completion 50.8%→65.5%；触发时在 RTX 4090 上增加 326 ms。RoboTwin 2.0 clean 66.4%→73.6%、randomized 62.8%→69.6%，LIBERO 96.9%→97.6%。
- **限制**：触发器依赖 flow policy 随机性；延迟只在单一 GPU 报告；LIBERO 增益较小。未见代码，且无独立复现。

#### Policy-Aligned Predictive Verification (PAV)

- **日期/版本**：2026-10-15，v1
- **链接**：[论文](https://arxiv.org/abs/2610.21434)
- **机制**：在 VLA 自身任务条件表示中评估候选 action prefix 与“成功继续”的兼容性；用 trajectory-survival supervision 与 localization prior 决定执行多少动作后再查询。
- **作者证据**：作者称在 π0、π0.5、LIBERO、RoboTwin 2 与真机操控中改善 success–query trade-off。
- **限制**：摘要没有统一可核对数字；终局监督对中间失败的归因可能不唯一；未见代码或独立复现。

#### ForkCast: Decide Whether and How to Intervene

- **日期/版本**：2026-10-13，v1
- **链接**：[论文](https://arxiv.org/abs/2610.18650)
- **机制**：用 candidate-conditioned latent world model 在相同未来时刻比较 Commit / Reobserve / Replan，并以共享任务进度头选择候选；无需独立失败检测器或改 VLA 权重。
- **作者证据**：RoboTwin 2 五任务、遮挡与滑移条件下 pooled success 13.3%→30%；跨两个 backbone；真机在候选适配后于 clean 与 visibility-limited 条件均优于基础策略。
- **限制**：只有三类固定候选；真机候选适配本身需要 rollout；代码标注为后续发布。

#### ACRO: Actor–Critic Rollout Orchestration

- **日期/版本**：2026-10-14，v1
- **链接**：[论文](https://arxiv.org/abs/2610.19677) · [项目页](https://junhoo.me/acro) · [官方代码](https://github.com/JunHoo-Lee/ACRO)
- **机制**：Critic 从固定 VLA rollout 学习 Q/V 成功前景，决定是否介入并从已执行轨迹选择 re-entry target；Trajectory Retraction 在已访问路径附近做物理回退，清空 action queue 后由同一 VLA 重新观察并继续。
- **作者证据**：GR00T N1.7 / π0.5，在 SimplerEnv、RoboCasa、真机同物理预算（含回退动作）下分别 +10.4、+7.3、+21.7 个百分点；真机 43.3%→65.0%。官方代码包含 critic、gate、回退规划与执行循环。
- **限制**：critic 需要该部署策略的 rollout；回退可能改变物体状态，且安全性取决于“已访问路径附近”假设。无独立复现。

#### Back on Track: Policy-Aligned Recovery with a Latent World Model

- **日期/版本**：2026-10-14，v1
- **链接**：[论文](https://arxiv.org/abs/2610.19579) · [项目页](https://policy-improvement-wm.pages.dev/)
- **机制**：固定黑盒策略外部学习 policy-conditioned liveness value 与紧凑 latent world model；检测进展丢失后短视规划纠正，再把控制权交还原策略。
- **作者证据**：作者报告 LIBERO-Goal 与 Franka 上对 π0.5 / diffusion policy 有显著提升，但摘要未给统一数字。
- **限制**：依赖有限标注 on-policy rollout 与 play data；项目页本次抓取失败，代码状态待核验。

#### When to Ask for Help: Value of Information for Slow-Module Scheduling

- **日期/版本**：2026-10-15，v1
- **链接**：[论文](https://arxiv.org/abs/2610.21160)
- **机制**：用决策论中的 Value of Information 决定何时调用昂贵慢模块，并把查询收益与成本放在同一标准下；同时审查检测器泄漏与语言反馈是否真的改变执行。
- **作者证据**：14 个闭环 arm 的 LIBERO 研究报告 cost ratio 跨 3 个数量级；929 条 trace 上检测 AUC 在去泄漏后从 0.93 降至 0.62；编译出的周期刷新策略距 oracle 2.4%。
- **限制**：单作者预印本，未见代码；语言重写在实验中未能可靠转化为查询收益，是有价值的负面结果而非完整机器人方案。

### 4. 长期记忆与快慢双系统

#### Value as Memory (VaM)

- **日期/版本**：2026-10-15，v1
- **链接**：[论文](https://arxiv.org/abs/2610.22368)
- **机制**：将近期 value predictions 缓存为任务进度记忆来条件化动作；在线真机 RL 混合离线示范、off-policy 干预与 on-policy rollout，从离线 warmup 过渡到稀疏奖励自主学习。
- **作者证据**：长时序形变与接触任务中，value caching 带来平均绝对成功率 +29.4%；在线自主学习相对 matched offline +32.8%。在相同 gradient-step 预算下策略迭代 8×，记录的每梯度步时间降低超过 2×。
- **限制**：均为作者报告；价值估计偏差可能成为压缩后的错误记忆；未见代码或独立复现。

#### LTM: Latent Transition Based In-Context Memory for VLA

- **日期/版本**：2026-10-15，v1
- **链接**：[论文](https://arxiv.org/abs/2610.21362) · [官方代码](https://github.com/buaa-colalab/LTM-pi)
- **机制**：存储连续观测的 compact latent transitions；冻结 latent-action encoder，仅训练轻量 adapter，并用 causal KV cache 与 delayed admission 控制内存预算；不需要语义标注或外部推理器。
- **作者证据**：RoboMME 58.54%、LIBERO-Mem 80.5%；10× 示范时 57.67%→87.50%；200-token 预算下 84% 对完整预算 87.5%；真机计数任务 11.25%→82.5%。
- **限制**：不同 benchmark 数字不可交叉排名；仓库已发布训练、cache、推理和测试代码，但数据/模型权重在外部提供，完整训练建议 8×H100。

#### PAM: Procedural Assistance Memory for Proactive Robots

- **日期/版本**：2026-10-15，v1（项目页标注 CoRL 2026）
- **链接**：[论文](https://arxiv.org/abs/2610.21211) · [项目页](https://davian-robotics.github.io/PAM/) · [作者链接仓库](https://github.com/DAVIAN-Robotics/PAM)
- **机制**：System 2 VLM 读取由活动阶段、trigger–action rules 与事件转移组成的 FSM memory，决定何时及做何种帮助；System 1 VLA 执行。每天结束由 reflection VLM 根据视频、动作史与反馈更新 PAM，不改权重。
- **作者证据**：5 天桌面辅助中 first-fire delay 约 5 s→1 s，并报告最高 precision/recall/F1；日常改变后一次 memory update 恢复；项目页还给出六个任务的逐项真机成功计数。
- **限制**：单一桌面日常、单用户式个性化；主动误触发的社会成本尚未充分量化。仓库存在且由项目页链接，但首页目前缺少论文 README，复现成熟度待核验。

#### Mem4Act: Learning Effective Latent Memory for Long-Horizon Manipulation

- **日期/版本**：2026-10-15，v1
- **链接**：[论文](https://arxiv.org/abs/2610.22323)
- **机制**：固定大小 control-oriented latent memory，结合多粒度时序聚合、问答监督与关键帧 DINO 重建，并采用 memory-first 两阶段训练。
- **作者证据**：作者报告 RoboMME 49.88%、RMBench 61.0%、四个真机任务 81.5%。
- **限制**：训练内生记忆而非可插拔 harness；跨论文分数受 backbone、数据与协议影响，不能与 LTM/MaP-WAM 直接排名。未见代码。

### 5. 在线 RL、自主数据与持续学习

#### ACCRUE: Continual Off-Policy RL for Robot Foundation Models

- **日期/版本**：2026-10-13，v1
- **链接**：[论文](https://arxiv.org/abs/2610.18596) · [项目页](https://accrue-rl.github.io/)
- **机制**：跨任务继承轻量 actor/critic；当前 critic 只指导当前任务，旧任务行为通过 retained episodes 上的 cached actor-target distillation 保持；固定视觉特征维持任务间兼容。
- **作者证据**：真机 π0.5 + FastTD3 的 AutoMate 新任务比单任务 RL 少 31.0%–68.5% 机器人交互，NIST 少 38.7%–42.9%；最终 6 个旧任务 118/120 次成功（98.3%）。
- **限制**：项目页明确机器人时间不含 demonstration collection 与训练 wall time；仿真点估计未显示不确定性；代码仍为 coming soon。

### 6. 世界模型、数字孪生与移动操作

#### WorldOracle: Benchmarking Action-Conditioned World Models

- **日期/版本**：2026-10-13 v1；2026-10-16 更新为 v2
- **链接**：[论文](https://arxiv.org/abs/2610.18826) · [项目页](https://worldoracle-benchmark.github.io/) · [官方代码](https://github.com/AgibotTech/WorldOracle) · [数据](https://huggingface.co/datasets/AgibotTech/WorldOracle)
- **机制**：给世界模型与真实系统相同的初始观测和低层动作序列，以 paired real execution 衡量 Physical State Correctness、Interaction Spatial Alignment、Key Interaction Area Fidelity 与 Multi-View Action Coherence；覆盖成功和失败的长多段轨迹。
- **作者/官方证据**：三种 embodiment、人工操作和策略 rollout 两种分布；官方仓库已发布评测代码、验证集接口与 leaderboard 提交流程。
- **限制**：它评估 world model，不直接证明闭环 recovery；live leaderboard 与论文使用不同 VLM evaluator，因此分数不可混用。

#### Cracking Mobile Manipulation

- **日期/版本**：2026-10-14，v1
- **链接**：[论文](https://arxiv.org/abs/2610.19600)
- **机制**：把失败拆成任务规划、导航/基座位置与局部操控；加入示范规划指导、adaptive visual memory、accessibility-aware base adjustment 和局部末端执行器修正。
- **作者证据**：固定 subtask VLA 在原子任务 80%，组合任务仅 19%；完整系统 RoboCasa365 19→47、held-out 18→49，BEHAVIOR-1K 14→37，真机 5/20→13/20。
- **限制**：是多个干预的 bundle，需要更细的组件消融；代码链接标注将来发布。无独立复现。

## 次级雷达

- **AutoAgent0**（[2610.18866](https://arxiv.org/abs/2610.18866)，2026-10-13 v1）：面向自动驾驶的 agentic runtime，以独立检测、规则验证和 action primitives 组成恢复回路；可迁移到机器人 harness，但并非机械臂实证。
- **P³-WAM**（[2610.22363](https://arxiv.org/abs/2610.22363)，2026-10-15 v1）：统一感知、预测与规划的 egocentric dexterous world-action model；与 harness 的关系主要是提供动作条件预测器，暂不列主表。
- **Harness²**（[2610.14224](https://arxiv.org/abs/2610.14224)，2026-10-09 v1，30 天范围）：无 ground-truth verifier 时用 Propose–Probe–Compose 做 task-level recursion，再更新 continual improvement harness；只有通用 agent benchmark，**并非机器人实证**，本周不作为机器人结果重复收录。

## 值得验证的研究假设

1. **介入策略应统一成成本敏感的多候选决策。** 在同一 VLA、任务和物理预算下，同时比较 Continue / Reobserve / Resample / Replan / Retract；报告净成功增益、介入精度、额外时间、危险动作与恢复后剩余预算。
2. **harness–executor 归因必须通过现实可执行的反事实。** 将 AdaRSI 的保存状态重试改为数字孪生分支或保守 real-world rewind，并用 SEAR 控制 reroll 与熟悉任务，检验归因是否仍成立。
3. **记忆可以采用三层混合：value、latent transition、procedural state。** value 提供连续进度，latent transition 保留视觉变化，FSM/PAM 提供可编辑的长期流程；需测错误记忆污染与冲突解决，而不只测最终成功率。
4. **经验编译需要显式的 chunk contract。** 为 ChunkAct/EmbodiedEvo 技能记录前置条件、后置条件、可观测失败证据、最大执行时长与 fallback；比较 token 节省是否以恢复延迟为代价。
5. **世界模型 benchmark 分数应预测真实 recovery utility。** 用 WorldOracle 的成败配对轨迹训练/评估 VeriVLA、ForkCast 类 verifier，测离线分数与真机候选排序、恢复成功的相关性。
6. **在线 RL 必须同时报告机器人时间、示范时间、训练 wall time 与人工干预。** ACCRUE 已明确部分排除项；把该口径扩展到 VaM、LWD 和 fleet learning，才能比较真实部署成本。
7. **主动服务的安全目标不仅是碰撞，还包括“不该帮时不帮”。** PAM 类系统应报告 false assistance、用户中断、错误习惯固化与撤销成本，并与 SafeHarness 式物理约束联合验证。
