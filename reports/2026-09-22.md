# Initial research review: 2026-09-22

Starting from the user's material dated 2026-09-08, this review reorganized the topic and checked original abstracts and project pages. It initially included 33 papers: 30 related to robotics and 3 offering methods from general-purpose agents. Three additional leads awaited primary-source verification. This does not claim complete coverage of all work available on the review date.

## Corrections to the starting material

1. **AgenticLab → PLanAR:** The original material linked to the older v3. The reviewed [v4](https://arxiv.org/abs/2602.01662v4) updates the title and contributions, emphasizing planning-language grounding, symbolic plans, and stepwise verification. It should not be categorized solely as a platform or benchmark.
2. **Revision tracking:** [SHAPER](https://arxiv.org/abs/2608.11350) had reached v2 on 09-10, and [LWD](https://arxiv.org/abs/2605.00416) v4 on 09-16. Identifying a version does not mean every experimental change has been checked.
3. **Do not infer dates from IDs:** ASPIRE's ID begins with 2607, but its original page gives 06-30 as the first-submission date. Arcadia's ID begins with 2512, but its first-submission date is 11-25.
4. **Qualify “only” and “the entire gap”:** The evidence supports LWD's reported fleet experiment scale, but does not exhaustively establish it as the only system. A memory oracle gap alone cannot prove that memory extraction explains the entire performance gap.
5. **ASPIRE's transfer scope:** The original abstract explicitly covers transfer across tasks, simulation/real-world settings, and embodiments. Cross-embodiment knowledge reuse still differs from online shared learning across robots; describing the evaluation as entirely homogeneous would be inaccurate.
6. **Keep the protocol with performance numbers:** This review does not combine LIBERO-Pro or RoboCasa scores from different papers into a leaderboard. Without matching budgets, perturbations, and models, those numbers do not establish that one system is better overall.

## Priority questions for further verification

- With the same VLM, what explains performance differences among semantic action interpreters, analytical tools, and frozen VLA interfaces?
- How should failure evidence and attempt history be selected for memory to reduce unproductive repetition?
- Can each skill update improve unseen tasks while passing regression tests on previous tasks?
- Which continual-learning methods retain an advantage after accounting for resets, verification, and human time?
