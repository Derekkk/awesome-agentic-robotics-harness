# RoboClaw

RoboClaw: An Agentic Framework for Scalable Long-Horizon Robotic Tasks

- First submitted: 2026-03-12; reviewed version: v3; latest revision: 2026-04-01
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: policy-learning, execution
- Interface / mechanism: self-reset + policy primitives
- [Paper](https://arxiv.org/abs/2603.11558)

## Mechanism overview

Combines forward manipulation and reverse recovery into a self-resetting loop, using a unified VLM controller to organize collection, learning, and deployment.

## Limitations and research questions

Task success and autonomous reset success are separate metrics.
