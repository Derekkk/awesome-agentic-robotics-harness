# RoboOS

RoboOS: A Hierarchical Embodied Framework for Cross-Embodiment and Multi-Agent Collaboration

- First submitted: 2025-05-06; reviewed version: v2; latest revision: 2025-06-05
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: fleet, execution, memory
- Interface / mechanism: brain + skill library
- [Paper](https://arxiv.org/abs/2505.03673)

## Mechanism overview

Organizes tasks and error correction across embodiments using an embodied brain, a modular skill library, and real-time shared memory.

## Limitations and research questions

State synchronization alone is not evidence that shared experience improves a policy.
