# HALTER

From Rollout to Reset: A Graph-Based Harness for Autonomous Long-Horizon Manipulation Evaluation

- First submitted: 2026-09-16; reviewed version: v1; latest revision: no additional revision recorded
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: verification, evaluation, policy-learning
- Interface / mechanism: scene graph + reset skills
- [Paper](https://arxiv.org/abs/2609.19413)

## Mechanism overview

Builds scene graphs and composes atomic reset skills for automatic scoring, reset planning, and reset verification in long-horizon evaluation.

## Limitations and research questions

Reset accuracy differs from policy task success; the evaluation initial-state distribution must also be recorded.
