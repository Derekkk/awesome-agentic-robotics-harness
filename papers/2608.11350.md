# SHAPER

Self-Evolving Embodied Agents via Skill-Harness Evolution

- First submitted: 2026-08-11; reviewed version: v2; latest revision: 2026-09-10
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`

## Mechanism overview

Keeps parameters frozen and uses environment rollouts to jointly optimize reusable skills and a context-code harness.

## Limitations and research questions

Check that target-environment adaptation data is separated from generalization tests.
