# MaP-WAM

Memory as Plans: World-Action Modeling with Memory-Grounded Planning

- First submitted: 2026-09-10; reviewed version: v1; latest revision: no additional revision recorded

- [Paper](https://arxiv.org/abs/2609.11561)

## Mechanism overview

Uses long histories for planning, compresses them into segment-level language and visual guidance, and predicts action chunks and execution progress with an action model.

## Limitations and research questions

A fixed executor context does not mean that planner cost stays constant as history grows.
