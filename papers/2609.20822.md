# SafeHarness

Coding Agents with an Obstacle-Aware Harness for Safe Robot Manipulation

- First submitted: 2026-09-17; reviewed version: v1; latest revision: no additional revision recorded
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: safety, execution, verification
- Interface / mechanism: obstacle-aware code
- [Paper](https://arxiv.org/abs/2609.20822)

## Mechanism overview

Turns obstacle-avoidance requirements into action choices during routing and contact, combining waypoint validation with replanning.

## Limitations and research questions

Report task success and collision avoidance separately; neither constitutes a formal safety guarantee.
