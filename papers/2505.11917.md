# OneTwoVLA

OneTwoVLA: A Unified Vision-Language-Action Model with Adaptive Reasoning

- First submitted: 2025-05-17; reviewed version: v2; latest revision: 2026-03-01
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: dual-system, execution
- Interface / mechanism: adaptive reasoning VLA
- [Paper](https://arxiv.org/abs/2505.11917)

## Mechanism overview

A unified model switches between reasoning and action as needed, co-trained on robot data and synthetic reasoning data.

## Limitations and research questions

Record switching triggers, end-to-end latency, and recovery from unexpected events.
