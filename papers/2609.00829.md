# HarnessEvolve

HarnessEvolve: Learning from Reference Trajectories for Reliable Agent Self-Evolution

- First submitted: 2026-09-01; reviewed version: v1; latest revision: no additional revision recorded
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: general-purpose agents; robotics transfer remains unverified
- Categories: reflection, skills, transfer
- Interface / mechanism: reference trajectory + gates
- [Paper](https://arxiv.org/abs/2609.00829)

## Mechanism overview

Uses reference trajectories for failure attribution and screens harness updates through quality and performance gates to reduce regressions.

## Limitations and research questions

Reference trajectories use answer information; robotics settings must prevent leakage of privileged information.
