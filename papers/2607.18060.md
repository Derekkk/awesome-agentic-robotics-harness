# RoboHarness (policy orchestration)

RoboHarness: Memory-Driven Orchestration of Heterogeneous Robot Policies for Long-Horizon Planning

- First submitted: 2026-07-20; reviewed version: v3; latest revision: 2026-09-29
- Reviewed on: 2026-10-09; verification scope: `primary_abstract`
- Scope: robotics
- Categories: execution, memory
- Interface / mechanism: heterogeneous policy routing + Memory Bridge
- [Paper](https://arxiv.org/abs/2607.18060)

## Mechanism overview

Packages heterogeneous robot policies as skills, uses memory to route tasks by capability, and bridges handoff states without jointly retraining the policies.

## Limitations and research questions

Distinct from RoboHarness arXiv:2603.24060. Evaluate routing gains separately from handoff improvements and account for each underlying policy and its training data.
