Harness VLA: Steering Frozen VLAs into Reliable Manipulation Primitives via Memory-Guided Agents

## Mechanism overview

Uses a frozen VLA as a retryable contact primitive, combining analytical tools with task and global memory to extend manipulation capabilities.

## Limitations and research questions

This does not imply that the entire robot system requires no training; results must specify the backbone and rollout budget.
