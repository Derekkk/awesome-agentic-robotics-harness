## Mechanism overview

A construction agent segments demonstrations into skills, trains and verifies one policy per proposed structural prior, and records each prior's applicability in an interface that a runtime agent reads to select and compose policies.

## Limitations and research questions

Simulation only (MetaWorld and ManiSkill); construction-time verification covers demonstrated skill-entry states and is not an out-of-distribution guarantee.
