# RegenHarness

RegenHarness: A Robot Agent Harness with Evidence-Gated Recursive Self-Improvement

- [Paper](https://arxiv.org/abs/2609.27612)

## Mechanism overview

Separates proposed actions from accepted task progress through evidence checks, versioned state, bounded recovery, and regression-gated changes to the harness configuration.

## Limitations and research questions

Real quadruped case studies demonstrate execution integration, not broad causal evidence of continual improvement. The reference runtime is single-host; weight updates are outside the proposed loop.
