# Fast-in-Slow

Fast-in-Slow: A Dual-System Foundation Model Unifying Fast Manipulation within Slow Reasoning

- First submitted: 2025-06-02; reviewed version: v1; latest revision: no additional revision recorded
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: dual-system
- Interface / mechanism: partially shared VLA
- [Paper](https://arxiv.org/abs/2506.01953)

## Mechanism overview

Embeds a fast execution module within a slow reasoning system through partially shared parameters, asynchronous frequencies, and heterogeneous inputs.

## Limitations and research questions

The reported 117.7 Hz uses chunk=8; it is not the number of independent VLM inferences per second.
