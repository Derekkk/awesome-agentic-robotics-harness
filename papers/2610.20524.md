# Temporal Flow Policy

Physical Time as a Missing Dimension of Robot Policy Memory Dynamics

## Mechanism overview

Learns memory transitions that preserve events and advance over measured physical intervals, conditioning diffusion and flow-matching robot policies on the resulting state.

## Limitations and research questions

This is a trained policy-memory mechanism, not a training-free agent wrapper. Match observation timing, history, architecture, and supervision when comparing memory designs.
