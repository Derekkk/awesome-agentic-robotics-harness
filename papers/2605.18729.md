# Robo-Cortex

Robo-Cortex: A Self-Evolving Embodied Agent via Dual-Grain Cognitive Memory and Autonomous Knowledge Induction

- First submitted: 2026-05-18; reviewed version: v1; latest revision: no additional revision recorded
- Reviewed on: 2026-09-22; verification scope: `primary_abstract`
- Scope: robotics
- Categories: memory, reflection, verification
- Interface / mechanism: dual-grain memory + heuristic induction
- [Paper](https://arxiv.org/abs/2605.18729)

## Mechanism overview

Distills navigation trajectories into reusable heuristics, combining short-term reflection, long-term principle memory, and Imagine-then-Verify planning.

## Limitations and research questions

The primary evidence concerns navigation and embodied question answering; it does not directly establish benefits for contact manipulation.
