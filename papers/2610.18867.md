# EmbodiedEvo

EmbodiedEvo: Self-Evolving Coding Agent For Physical Intelligence

## Mechanism overview

Distills execution feedback into reusable code skills and diagnostic lessons, then freezes this experience for independent agents in unseen scenes without weight updates.

## Limitations and research questions

Experience is collected on one scene per task before evaluation; this is not experience-free execution or proof of unseen-task transfer. RoboDojo-Sim scores do not establish real-robot performance.
